# 🧮 Math Interactive Simulators & Visualizers

**Project Author:** Alexander Moiseenko
A collection of fully functional interactive programs with a graphical user interface (Tkinter, Matplotlib) designed for visual learning of school and university mathematics. 

## 🚀 Modules included:

### 1. 📈 Polynomial Division Simulator (Long Division & Horner's Scheme)
* **For Schools:** Step-by-step polynomial long division, math test generator (4 options) with automatic PDF export (with answer keys for teachers), "Find the mistake" game mode, and blitz tests.
* **For Universities:** Euclidean algorithm for finding the GCD of polynomials, factorization over the complex plane, Chinese Remainder Theorem (CRT), and computations in finite Galois fields GF(2) via XOR (cryptography).

### 📐 2. Interactive Trigonometry
* Dynamic visualization of the trigonometric unit circle.
* Helps students visually understand how sines, cosines, tangents, and cotangents change during angle rotation and how wave graphs (sinusoids) are plotted.

### 🕸 3. Graph Theory Visualizer
* A tool for building, editing, and interactively analyzing graphs.
* Visual demonstration of vertices, edges, pathfinding, and classic graph algorithms that often cause difficulties for students.

### 🎲 4. Intelligent Solver for Word Problems and Probability
* Modeling of complex multi-step probability problems (e.g., independent repeated trials, Bernoulli schemes).
* Generator and analysis of word problems regarding percentages, alloys, mixtures, and motion.

## 🛠 Tech Stack:
* **Language:** Python 3
* **GUI:** Tkinter / ttk
* **Math & Charts:** NumPy, Matplotlib
* **Documents:** ReportLab (PDF generation)
