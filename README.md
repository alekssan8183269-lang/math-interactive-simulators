# 🧮 Комплекс интерактивных тренажёров и визуализаторов по математике(math-interactive-simulators)

**Автор проекта:** Моисеенко Александр

Сборник полностью рабочих интерактивных программ с графическим интерфейсом (Tkinter, Matplotlib), созданных для наглядного обучения школьников и студентов. Проект призван перевести абстрактные математические формулы в интерактивные визуальные модели, которые «можно покрутить».

---

## 🚀 Модули, входящие в комплекс:

### 1. 📈 Симулятор деления многочленов (Уголком и Схема Горнера)
* **Для школы:** Пошаговое деление полиномов столбиком, генератор контрольных работ на 4 варианта с автоматическим экспортом в PDF (с ключами для учителя), игровой режим «Найди ошибку» в знаках, блиц-тесты.
* **Для ВУЗов:** Алгоритм Евклида для поиска НОД многочленов, разложение на неприводимые множители в комплексной плоскости, Китайская теорема об остатках (КТО) и вычисления в конечных полях Галуа $GF(2)$ через XOR (криптография).

### 📐 2. Интерактивная тригонометрия
* Визуализация тригонометрического круга «в динамике».
* Помогает учащимся наглядно понять, как изменяются синусы, косинусы, тангенсы и котангенсы при вращении угла, и как строятся графики волн (синусоиды).

### 🕸️ 3. Визуализатор теории графов
* Инструмент для построения, редактирования и интерактивного анализа графов.
* Наглядная демонстрация вершин, ребер, поиска путей и классических алгоритмов на графах, которые часто вызывают сложности у школьников.

### 🎲 4. Интеллектуальный решатель текстовых задач и вероятности
* Моделирование сложных многошаговых задач на вероятность (например, независимые повторные испытания, схемы Бернулли, стрельба по мишеням до $N$ промахов/попаданий).
* Генератор и разбор текстовых задач на проценты, сплавы, смеси и движение.

---

## 🛠️ Стек технологий:
* **Язык:** Python 3
* **Интерфейс:** Tkinter / ttk
* **Математика и графики:** NumPy, Matplotlib
* **Документы:** ReportLab (генерация PDF)

## 📦 Как запустить?
Каждая программа может быть запущена как из исходного кода (`.py`), так и через готовые скомпилированные `.exe` файлы, которые не требуют установки Python и находятся в разделе **Releases** к каждому модулю.
